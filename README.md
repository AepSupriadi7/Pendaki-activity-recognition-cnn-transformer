# Analisis Spasial-Temporal Aktivitas Pendaki Gunung 🏔️

Project ini menggunakan arsitektur **Hybrid CNN-Transformer** untuk mengenali pola gerakan pendaki gunung melalui sensor smartphone secara offline.

### Metodologi Utama:
* [cite_start]**Sensor Fusion:** Menggabungkan data Accelerometer, Gyroscope, dan Barometer[cite: 76, 163].
* [cite_start]**Deep Learning:** Menggunakan CNN untuk fitur spasial dan Transformer untuk dependensi temporal[cite: 67, 194].
* [cite_start]**Hasil:** Akurasi klasifikasi mencapai **93,65%** pada data uji[cite: 504].
